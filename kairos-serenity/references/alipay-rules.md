# 支付宝基金定投规则

> 基于支付宝官方规则 + QDII 基金实操经验整理。每次持仓诊断时加载此文件，确保建议与平台规则匹配。

## 一、定投基本参数

| 参数 | 规则 |
|------|------|
| 最低金额 | **10 元/期**（单笔最低） |
| 定投周期 | 每日 / 每周 / 每两周 / 每月 |
| 扣款时间 | 设定周期的交易日自动扣款 |
| 扣款来源 | 余额宝 / 银行卡 / 余额 |
| 智能定投 | 支持（参考均线等指标动态调整金额） |

## 二、QDII 基金特殊规则

### 2.1 限购机制

QDII 基金受制于基金公司外汇额度，经常设置单日申购上限：

- **单日限额**：常见如 100 元/日、500 元/日、1000 元/日
- **暂停申购**：额度耗尽时完全暂停，仅允许赎回
- **不同基金公司额度独立**：可通过分散基金公司来放大总买入量

### 2.2 交易确认时效

| 时间点 | 说明 |
|--------|------|
| T 日 | 发起申购/定投 |
| T+1 日晚 | 公布净值 |
| T+2 日 | 确认份额，查看盈亏 |
| T+3 日+ | 赎回到账（比 A 股慢） |

> 净值存在"滞后性"——看到的净值实际是前一日收盘价，不适合短线操作。

### 2.3 扣款失败场景

| 场景 | 结果 |
|------|------|
| 定投金额 > 单日限额 | 超出部分确认失败 |
| 多渠道合并超限（支付宝 + 天天基金等） | 合并计算，超出部分失败 |
| 节假日非交易日集中顺延 | 多笔定投集中到节后第一个交易日，可能只成功一笔 |
| 余额/银行卡余额不足 | 确认失败 |
| 连续扣款失败 3 次 | 定投计划**自动暂停**，需手动恢复 |

### 2.4 应对限购的实操策略

1. **拆分定投日**：如限额 100/日，可周二/周四各投 100，周买入 200
2. **多只同类基金分散**：不同基金公司 QDII 额度互相独立
3. **使用"预约买入"**：一笔钱按每日限额自动买入直到买够目标金额（比定投更适合限购场景）
4. **场内 ETF 替代**：场内跨境 ETF 不限购，但需注意溢价风险
5. **基金公司直销 APP**：通常比支付宝等代销渠道额度更宽松

## 三、定投计划管理

| 操作 | 路径 |
|------|------|
| 查看/修改/暂停 | 支付宝 → 理财 → 基金 → 持有 → 定投计划 |
| 终止定投 | 同上路径，终止后未使用红包失效 |
| 恢复定投 | 暂停后可随时手动恢复 |
| 修改金额/周期 | 可调整，下次扣款生效 |

## 四、对持仓诊断的影响

在给出定投方案建议时，必须检查以下约束：

1. **单只基金日定投金额 ≤ 该基金当前单日限额**（需查询最新限额）
2. **同一基金公司多只基金日定投总和 ≤ 该公司总限额**（如适用）
3. **避免同一基金设置多笔同日定投**（顺延风险）
4. **QDII 限购基金优先建议"预约买入"替代定投**
5. **限购/暂停中的基金标注原因并给出替代方案**

## 五、费用结构

| 费用类型 | A 类份额 | C 类份额 |
|----------|---------|---------|
| 申购费 | 有（定投通常打 1 折，0.12%-0.15%） | 无 |
| 赎回费 | 持有 2 年以上通常免 | 持有 30 天以上通常免 |
| 销售服务费 | 无 | 0.2%-0.8%/年 |

> 定投频率极高（日定投）时，C 类份额通常更合算——免申购费，且每笔小额申购费对 A 类不友好。
